# Fsaverage implementation and sub-03 review

The intended experiment is test-subject EEG reconstructed with fsaverage BEM
and source anatomy. Script 01 explicitly sets `model_subject=fsaverage` for
all 5,124 jobs (732 LOSO and 4,392 reference-selected parameter jobs).
There are **61 distinct test runs total across seven subjects**, not 61 per
subject. Only Scripts 01–03 currently exist; no completed fsaverage inverse
experiment is demonstrated by the present output tree.

## Confirmed implementation issue and repair

All seven original Script 03 MRI registrations failed. The sub-03 log shows
ANTs trying `DATASETSSOURCELOCALIZATION` instead of the real directory
`DATASETS SOURCE LOCALIZATION`. The installed shell wrapper loses whitespace
in input paths and still returns zero. Missing expected transform files were
correctly classified as failures, but the old reason `ANTs exit 0` was unclear.

`03_register_ground_truth.py::run_registration` now uses temporary input and
output symlinks with whitespace-free relative names. Original MRIs are unchanged.
A `command.json` records original paths and wrapper arguments. Required output
files must exist and be nonempty; failure reasons name missing/empty outputs.

Verification: a temporary fake wrapper successfully resolved input paths and
created output through aliases even when original input/output paths contained
spaces; script syntax compiled. A fresh `--phase audit` completed at
`outputs/03_register_ground_truth_pathfix_audit`. This verifies input inventory
and coordinate prerequisites, not successful ANTs registration. Full registration
has not been rerun in this review.

## Sub-03: confirmed residuals and unresolved cause

Script 02 fits a rigid, unscaled, trimmed nearest-scalp ICP, initialized using
the built-in fsaverage transform. It uses forward-file electrode coordinates;
it does not constrain the fit using subject-specific fiducials.

| Metric | Fsaverage fitted scalp | Native scalp diagnostic |
|---|---:|---:|
| Median distance, mm | 4.566 | 9.764 |
| 95th percentile, mm | 22.597 | 20.691 |
| Maximum, mm | 44.678 | 34.718 |

The fsaverage fit fails the existing p95 <=20 mm gate. Native and template
residuals use different geometry/alignment and cannot alone diagnose acquisition
error. Sub-02 also has a high native p95 (22.681 mm), so this is not unique to
sub-03. Scalp proximity and roundtrip accuracy do not prove anatomical alignment.

Largest sub-03 template residuals include e252 (44.678 mm; native 34.718),
e248 (43.312; native 29.773), and e250 (33.457; native 23.245). Inspection of
the existing 3-D template overlay confirms a concentration in the left anterior
and inferior region. This is compatible with local geometry mismatch, peripheral
sensor placement, or coordinate issues; the cause remains unresolved.

The existing diagnostic manifest reports all 588 sub-03 jobs use at least one
sensor >20 mm from the template scalp. Montage p95 alone hides some individual
outliers and must not override the failed subject-level audit.

## Coordinate provenance limits

`_01_preprocess.py` loads subject-specific `*_egi_dig.hpts` with millimetre
units before attaching the montage. Those HPTS files were not found in the
local released Localize-MI dataset. This historical script does not establish
that each current released forward used those original files.

The sub-03 EEG coordinate sidecar labels electrode coordinates and landmarks
as T1w, in metres, while Script 02 explicitly reads HEAD-frame forward channels.
Direct TSV-versus-forward RMS differences therefore mix a potential frame
mismatch with any data mismatch. They must not be interpreted as digitization
error without a verified frame conversion. Identical electrode TSV hashes
across subjects remain a provenance concern and justify not substituting these
TSVs for subject-specific geometry.

## Next methodological steps

Retain sub-03's FAIL status pending review. Verify digitization/forward provenance
and fiducial frame definitions before changing alignment. Compare anatomically
anchored coregistration against current ICP across all seven subjects. If an
independently justified channel subset is needed, freeze its rule and document
a separate sensitivity analysis with newly matched forwards and EEG channels.
Do not silently project outliers, relax thresholds, or exclude the whole subject.

For reconstruction, use test EEG and sensor geometry, a reviewed test-head to
fsaverage transform, fsaverage BEM/source space, and frozen selected parameters.
Reference identity identifies the parameter/channel-selection condition; it must
not select the anatomical model. MRI registration of stimulation truth is a
separate evaluation operation and must not feed truth locations into fitting.


## Follow-up: available fiducials and export code

A new inventory at `outputs/02_fiducial_provenance_review/01_sidecar_landmarks.csv`
confirms all seven EEG sidecars contain exactly the same landmark coordinates.
Direct MNE inspection of sub-01 and sub-03 forwards found no `info["dig"]`
entries. Their MRI-to-head transforms have identity rotations and differing
translations. These facts prevent independent fiducial verification from those
forward files; they do not establish invalidity of the electrode locations.

`fx_bids.py::make_coordsys_eeg_json` copies epoch digitization landmarks and
labels them T1w without applying an MRI transform. Its
`make_electrodes_eeg_tsv` also copies channel `loc` values directly.
`fx_bids.py::load_bids` then interprets the released geometry as HEAD coordinates.
This confirms an inconsistency in the code's coordinate labeling, although it
does not establish the exact export history of every released file. Do not
use the sidecar T1w label alone as evidence of anatomical landmark provenance.

The repaired full MRI registration was started in the new output directory
`outputs/03_register_ground_truth_pathfix`. Its acceptance requires the final
status CSV, finite mapped ground-truth coordinates, point roundtrip checks, and
anatomical overlay review. The old failed output folder is preserved.

The appropriate next electrode step is to obtain the original digitization
and coregistration provenance, or identify independently documented landmarks
in available native anatomy. Reusing identical sidecar landmarks or mechanically
projecting outlying electrodes cannot independently validate sub-03. Any
alternative montage/coregistration must remain a labeled sensitivity condition.
